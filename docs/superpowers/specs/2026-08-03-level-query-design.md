# [等级查询] 模块设计文档

日期：2026-08-03
状态：已确认（设计讨论完成）

## 1. 背景与目标

在跑研社（uni-app，微信小程序 + H5）中新增 [等级查询] 模块：用户输入 项目 / 性别 / 最好成绩 / 年龄，查询自己当前处于的马拉松或半程马拉松等级，并始终展示对应的等级标准表。

## 2. 需求要点（来自 context_md/level.md，经确认）

- **级别枚举（由低到高）**：大众二级 → 大众一级 → 大众精英 → (专业)三级运动员 → (专业)二级运动员 → (专业)一级运动员 → 运动健将 → 国家健将
- **(专业)三级/二级/一级运动员** 即表格中的 三级/二级/一级运动员；**国家健将** 即数据中的 **国际健将**
- **达标规则（已确认）**：成绩 **严格小于** 标准线才算达到该级别；取所有达标级别中的最高者。全不达标显示："未达标任何级别,请继续努力!"
- **表格区域**：无论是否点击查询都显示；跟随所选 项目 + 性别
- **数据来源**：用户整理于 `context_md/level-data.md`（田协标准）

## 3. 数据文件 `src/data/level.json`

结构：`项目(马拉松/半程马拉松) → 性别(男子/女子) → { 大众: { 大众二级/大众一级/大众精英: { 年龄组: 时间 } }, 专业: { 三级运动员/二级运动员/一级运动员/运动健将/国际健将: 时间 } }`

- **大众等级** 按年龄组（8组）查表：34岁以下、35～39岁、40～44岁、45～49岁、50～54岁、55～59岁、60～64岁、65岁以上
- **专业等级** 不分年龄，固定值
- 时间统一 "H:MM:SS" 字符串，复用 `src/utils/time.js` 的 `parseTimeToSeconds()` 转秒比较
- 具体数值以 `context_md/level-data.md` 为准（全文转录，无换算、无推导）

## 4. 业务逻辑 `src/logic/level-query/`

### constants.js
- `PROJECTS`：['马拉松', '半程马拉松']
- `GENDERS`：['男子', '女子']
- `AGE_GROUPS`：['34岁以下', '35～39岁', '40～44岁', '45～49岁', '50～54岁', '55～59岁', '60～64岁', '65岁以上']
- `LEVELS_LOW_TO_HIGH`：['大众二级', '大众一级', '大众精英', '三级运动员', '二级运动员', '一级运动员', '运动健将', '国际健将']
- `MASS_LEVELS`（大众，需年龄组）、`PRO_LEVELS`（专业，固定）
- `getAgeGroup(age)`：18~34 → '34岁以下'；35~39 …；65~100 → '65岁以上'
- `getLevelDisplayName(level)`：显示名映射表 — 三级/二级/一级运动员 → "(专业)三级/二级/一级运动员"；国际健将 → "国家健将"；其余同字
- 选择器范围：`HOUR_RANGE`(0~6)、`MIN_SEC_RANGE`(00~59)、`AGE_RANGE`(18~100)

### calculator.js
- `queryLevel({ project, gender, age, totalSeconds })`：
  - 定位 `levelData[project][gender]`，大众级别按 `getAgeGroup(age)` 取值，专业级别取固定值
  - 遍历 `LEVELS_LOW_TO_HIGH`，凡 `totalSeconds < 标准秒数` 记为达标并更新结果，最终返回级别 key
  - 全不达标返回 `null`

## 5. 页面 `src/pages/level-query/index.vue`

- **header**：橙色 `#F39C12`，标题"等级查询"，左侧 ← 返回（`uni.navigateBack()`）
- **输入区**（卡片）：
  - 项目：chips（马拉松 / 半程马拉松，默认马拉松）
  - 性别：chips（男子 / 女子，默认男子）
  - 最好成绩：`picker mode="multiSelector"` 时:分:秒，时0~6、分00~59、秒00~59，默认 3:00:00
  - 年龄：`picker mode="selector"` 18~100，默认 30
  - [查询] 按钮：校验输入（成绩 > 0），计算并显示结果；成绩为 0 时 toast 提示
- **结果区**（`v-if` 查询后显示）：卡片「你的级别：{getLevelDisplayName(level)}」；`null` 时显示"未达标任何级别,请继续努力!"
- **表格区**（始终显示，跟随所选 项目 + 性别）：
  - 专业表：5 行（国际健将 → 三级运动员，从高到低），列：级别 | 成绩
  - 大众表：8 行（年龄组），列：年龄组 | 大众精英 | 大众一级 | 大众二级（从高到低）
  - 分享截图时展开为完整表格（参照 pace-calculator 的 `table-body-expand` 模式）
- **操作按钮**（`v-show="!sharing"`）：
  - 分享：H5 条件编译 + `@/utils/share` 的 `captureAndShare`，隐藏操作按钮后截图下载
  - 返回首页：`uni.switchTab({ url: '/pages/index/index' })`
  - 重新录入：重置 项目/性别/时间/年龄 为默认值，隐藏结果区

## 7. 明确不做的（YAGNI）

- 不做性别之外的其它维度（如枪声/净成绩、赛事认证判定）
- 不做等级证书/申请入口等延伸功能
- 不在 H5 之外平台做分享截图（与现有页面一致，小程序侧提示"请在浏览器中打开"）
