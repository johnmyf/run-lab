# 配速计算器 设计文档

## 概述

配速计算器是跑研社（RunLab）应用的第九个功能模块，用户输入跑步距离和目标时间后，计算并展示每公里分段配速表格，支持匀速和变速策略。

## 技术栈

- uni-app 3.0 (Vue 3, Composition API, `<script setup>`)
- 微信小程序 + H5 双平台

## 路由配置

路径：`/pages/pace-calculator/index`
已在 `pages.json` 中配置，页眉颜色：青色 `#00BCD4`

## 核心数据结构

### 距离配置 (`constants.js`)

```js
export const DISTANCES = [
  { key: '5k',     label: '5公里',        km: 5 },
  { key: '10k',    label: '10公里',       km: 10 },
  { key: '15k',    label: '15公里',       km: 15 },
  { key: 'half',   label: '半程马拉松',    km: 21.0975 },
  { key: 'marathon', label: '马拉松',     km: 42.195 },
]

export const INTERVAL_OPTIONS = [
  { value: 1, label: '1公里' },
  { value: 5, label: '5公里' },
]

export const SEGMENTS = 5           // 固定5段
export const STRATEGY_MIN = -10     // 先慢后快
export const STRATEGY_MAX = 10      // 先快后慢
export const STRATEGY_STEP = 1      // 步长
```

### 输入模型

```
{
  distanceKey: string,   // '5k' | '10k' | '15k' | 'half' | 'marathon'
  hours: number,         // 0-6
  minutes: number,       // 0-59
  seconds: number,       // 0-59
  strategy: number,      // -10 ~ +10
  interval: number       // 1 或 5
}
```

### 输出表格行

```
{
  km: number,            // 公里数（最后行可能为小数）
  cumulativeTime: string, // "05:41" 或 "01:23:45"
  pace: string           // "5'41\""
  totalSeconds: number   // 累计秒数（供内部使用）
}
```

## 核心算法 (`calculator.js`)

### 1. 计算平均配速

```
totalSeconds = hours × 3600 + minutes × 60 + seconds
totalKm = DISTANCES[distanceKey].km
avgPaceSeconds = totalSeconds / totalKm    // 每公里秒数（浮点数）
```

### 2. 非匀速策略 — 5 段配速计算

```
S = strategy（-10 到 +10）
r = S / 100 / SEGMENTS    // 段间变化率，如 -10% → r = -0.02

各段配速 = P × (1 + r)^(k-1), k = 1..5

总时间约束：
Σ(D/5 × P × (1+r)^(k-1)) = totalSeconds

→ P = totalSeconds × 5 / (D × Σ(1+r)^(k-1))

当 S=0（匀速）：每公里配速 = totalSeconds / D
```

### 3. 逐公里累计与余数分配

```
每段内公里数 N = D / SEGMENTS（浮点数）
每公里理论配速 = 段配速秒数（浮点数）

对 N 公里逐行累计：
- 当前公里配速 = 段配速向下取整到整数秒
- 累计该段的余数秒数
- 每段内余数达到 1 秒时，分配给下一行（配速 +1 秒）
- 余数按均匀间隔分配（段内行数 ÷ 余数秒数 的间隔）
```

### 4. 按显示间隔生成表格

```
间隔 1km：每公里一行 + 总距离尾行
间隔 5km：每 5 公里一行（分段平均配速）+ 总距离尾行

最后一行总是精确的总距离公里数和目标时间
```

### 5. 分段平均配速（间隔5km时）

```
第 N 公里行的配速 = km(N-4) 到 km(N) 这 5 公里的平均配速
（即该 5km 段的平均配速）
```

| 交互 | 行为 |
|------|------|
| 点击距离单选 | 选中高亮，清除计算结果 |
| 修改时间选择器 | 更新时/分/秒，清除计算结果 |

| 拖动配速策略滑杆 | 拖动结束后重新生成表格 |

| 点击返回首页 | `uni.switchTab` |
| 点击重新评估 | 滚动回顶部输入区 |

## 边界情况处理

- **时间必须大于 0**，否则点击"计算"时提示
- **策略值 0（匀速）**：所有公里配速相同，仅余数分配导致 ±1 秒差异
- **极短距离 + 大策略值**：段内公里数可能 < 1，算法仍然适用
- **毫秒级精度**：内部用浮点数秒计算，显示时向下取整到秒
- **距离显示**：半马精确值 21.0975km，表格尾行显示 21.098（3 位小数）；马拉松 42.195km
