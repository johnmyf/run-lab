# 首页九宫格布局调整设计方案

## 概述

调整跑研社首页 3×3 九宫格功能面板布局：移除一个"待开发"占位，新增"配速计算器"功能模块，并重新排列三个现有模块的位置。

## 目标布局

| | 第1列 | 第2列 | 第3列 |
|---|---|---|---|
| 第1行 | 跑力值计算 ⚡ `#3498DB` | 成绩预测 🏆 `#E74C3C` | 心率计算 ❤️ `#2ECC71` |
| 第2行 | **配速计算器** ⏱️ `#00BCD4` | **跑步课表** 📅 `#9B59B6` | **交流天地** 💬 `#F39C12` |
| 第3行 | **成就体系** 🏅 `#1ABC9C` | 待开发 🔜 `#95A5A6` | 待开发 🔜 `#95A5A6` |

## 变更前后的映射关系

| 功能模块 | 原位置 | 新位置 | 变更 |
|---|---|---|---|
| 跑力值计算 | (1,1) | (1,1) | 不变 |
| 成绩预测 | (1,2) | (1,2) | 不变 |
| 心率计算 | (1,3) | (1,3) | 不变 |
| 配速计算器 | — | (2,1) | **新增**，浅蓝 #00BCD4，⏱️ |
| 跑步课表 | (2,1) | (2,2) | 后移一列 |
| 交流天地 | (2,2) | (2,3) | 后移一列 |
| 成就体系 | (2,3) | (3,1) | 移至第3行第1列 |
| 待开发 | (3,1) | 删除 | **移除** |
| 待开发 | (3,2) | (3,2) | 不变 |
| 待开发 | (3,3) | (3,3) | 不变 |

## 需修改的文件

### 1. `src/pages/index/index.vue`
- `menuItems` 数组重新排序
- 新增配速计算器项：`{ id: 4, title: '配速计算器', icon: '⏱️', colorClass: 'cyan', path: '/pages/pace-calculator/index' }`
- 移除一个 `{ title: '待开发', ... }` 项
- 新增 `.grid-item.cyan { background: #00BCD4; }` CSS 样式

### 2. `figma_design.json`
- `designSystem.colors` 新增 `"cyan": "#00BCD4"`
- 九宫格容器内 children 重新排序
- 新增配速计算器组件节点（`#00BCD4`，⏱️）
- 移除一个待开发组件节点

### 3. `figma_design_visual.html`
- grid items 顺序调整
- 新增配速计算器卡片（cyan 样式）
- 新增 `.grid-item.cyan { background: #00BCD4; }` 样式
- 移除一个待开发卡片

### 4. `src/pages.json`
- `pages` 数组中新增 `{ path: "pages/pace-calculator/index", style: { navigationStyle: "custom" } }`

### 5. 新建 `src/pages/pace-calculator/index.vue`
- 遵循项目页面组件约定
- 顶部浅蓝 header（`#00BCD4`）+ ← 返回按钮 + 居中标题"配速计算器"
- 居中内容区显示"开发中"占位
- 设置 `navigationStyle: "custom"`

## 设计系统扩展

- `designSystem.colors` 新增 `cyan: "#00BCD4"` 色值
- 与现有浅青色 `#1ABC9C`（teal/成就体系）形成区分

## 不变的部分

- 底部 tabBar（首页 / 我的）配置不变
- 首页顶部导航栏、欢迎区域、功能面板标题不变
- 其余功能页面（跑力值计算、成绩预测等）不受影响
- 成就体系页面仍同时作为 tabBar "我的" 页面
