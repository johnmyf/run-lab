# 跑步工具跨平台应用

基于 uni-app 框架构建的跑步工具应用，同时支持微信小程序和 H5 网页双平台。采用 3x3 九宫格设计，可灵活扩展功能模块。

### 它能帮你做什么

**🧭 看清自己的水平**

- **跑力值计算**：输入近期跑步成绩（5 公里、10 公里、半马、全马等），小程序基于运动科学帮你算出一个跑力值，直观反映你的真实跑步水平。

**🎯 制定目标与训练**

- **成绩预测**：有了跑力值，就能直接预测从 1500 米到马拉松共 7 个距离的成绩，还会给出训练配速建议，告诉你该用什么速度练。

**⏱️ 日常跑步计算**

- **配速计算器**：知道距离和目标时间，帮你算该保持的平均配速。
- **完赛时间计算**：知道距离和配速，帮你估算完赛时间。
- **步频步幅计算**：步频、步幅互相换算，帮你了解自己的跑步节奏。

**❤️ 更懂自己的身体**

- **心率计算**：输入年龄、性别，估算最大心率，跑步时把强度控制在合适区间。
- **体重建议**：输入体重、身高、性别，计算 BMI，判断成人身体状态并给出跑者层级参考。

**🏅 更多玩法**

- **等级查询**：对照标准，看看你的最好成绩属于什么等级。
- **跑步课表**（开发中）：训练计划管理，敬请期待。
- **成就体系**（开发中）：跑步成就与徽章（仅保留底部 tabBar「我的」入口）。

### 为什么跑步要讲科学？

很多跑者靠感觉练：状态好就猛冲，累了就慢慢跑，进步慢，还容易受伤。科学训练，就是用数据代替感觉：

- **知道水平**：跑力值把 5 公里、全马等各种成绩换算成同一个数字，你的水平一目了然，进步看得见。
- **知道强度**：不同目标对应不同配速和心率区间。太快容易疲劳受伤，太慢等于白跑，数据帮你练得刚刚好。
- **知道目标**：比赛目标不是拍脑袋定的。基于当前水平预测成绩、规划配速，目标才现实、才敢冲。
- **看得见进步**：每次训练有数据留痕，跑没跑到位、有没有变强，一查便知。

跑研匠把这些复杂的计算做成了现成工具：不用查表、不用背公式，输入几个数字，科学训练马上开始。

打开小程序 → 点击九宫格里的功能 → 输入数据 → 立即得到结果。

## 功能模块

九宫格共 9 个功能模块，其中 8 个已实现、1 个开发中。成就体系已从九宫格移除，仅保留底部 tabBar「我的」入口。

1. **跑力值计算** ⚡ - 输入近期跑步成绩（5km/10km/15km/半马/全马），对照 Jack Daniels VDOT 表格计算跑力值
2. **成绩预测** 🏆 - 基于 VDOT 值直接查表预测 7 个距离（1500米~马拉松）的理论成绩，并给出训练配速建议
3. **等级查询** 🥇 - 对照大众/专业运动员标准，查询成绩对应等级
4. **步频步幅计算** 👟 - 配速、步频、步幅三者互相换算
5. **配速计算器** ⏱️ - 给定距离和目标时间，计算平均配速及分段配速
6. **完赛时间计算** 🏁 - 给定距离和平均配速，估算完赛时间及分段配速
7. **心率计算** ❤️ - 输入年龄、性别，多公式估算最大心率，划分 5 个训练区间
8. **体重建议** ⚖️ - 输入体重、身高、性别，计算 BMI，给出成人身体状态与跑者层级建议
9. **跑步课表** 📅 - 训练计划管理（开发中）

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动 H5 网页开发服务器

```bash
npm run dev:h5
```

## 页面说明

### 首页（pages/index/index）

- 深蓝色顶部导航栏，标题"跑步工具"
- 欢迎信息卡片
- 3x3 九宫格功能面板，点击跳转对应功能页
- 底部 tabBar（"首页"和"我的"两个标签，深蓝底色）

### 功能页面

已实现的功能页采用表单交互模板：顶部彩色 header + 选择/输入区 + 结果展示区。未实现的页面为占位状态（功能图标 + 标题 + "开发中"提示 + 施工动画）。

#### 跑力值计算页（已实现）
- **数据源**: `src/data/sheet5-1.json` — Jack Daniels VDOT 表，56 个 VDOT 值 × 9 个距离
- **输入**: 5km / 10km / 15km / 半马 / 全马 最快成绩（选填）
- **算法**: 各输入成绩查 VDOT 表 → 取对应 VDOT 最大值
- **输出共享**: VDOT 值通过 `uni.setStorageSync('vdot', value)` 全局共享，供成绩预测页使用

#### 成绩预测页（已实现）
- **输入**: 读取跑力值页面的 VDOT 值
- **算法**: 直接查 `sheet5-1.json`，**无公式推导**
- **预测项**: 1500米 / 3公里 / 5公里 / 10公里 / 15公里 / 半程马拉松 / 马拉松
- **标签规则**: 半程马拉松和马拉松不显示"跑步"，其余显示（如 `1500米跑步`）
- **分享**: H5 平台 html2canvas 截图下载，分享时隐藏操作按钮

#### 心率计算页（已实现）
- **输入**: 年龄（10-99）、性别
- **算法**: 三种公式估算最大心率 — 传统公式 `220-年龄`、Tanaka `208-0.7×年龄`、Gulati（区分性别）
- **输出**: 最大心率估算结果 + 5 个训练区间（热身/燃脂/有氧耐力/乳酸阈/无氧），见 `src/logic/heart-rate/constants.js`

#### 配速计算器页（已实现）
- **输入**: 距离（5公里~马拉松，支持自定义 3~300 公里）、期望完成时间
- **算法**: `src/logic/pace-calculator/calculator.js`
- **输出**: 平均配速 + 按策略划分的分段配速（策略、分段区间见 `constants.js`）

#### 完赛时间计算页（已实现）
- **输入**: 距离、平均配速
- **算法**: `src/logic/finish-time/calculator.js`（复用配速计算器的距离配置与分段计算）
- **输出**: 完赛时间 + 分段配速表

#### 等级查询页（已实现）
- **数据源**: `src/data/level.json`
- **输入**: 项目（马拉松/半程马拉松）、性别、最好成绩、年龄
- **算法**: `src/logic/level-query/calculator.js`
- **输出**: 成绩对应等级（大众二级 ~ 国际健将，见 `src/logic/level-query/constants.js`）

#### 步频步幅计算页（已实现）
- **输入**: 三种计算模式，见 `src/logic/cadence-stride/constants.js` 的 `MODE_OPTIONS` — 由步频和步幅计算配速 / 由配速和步幅计算步频 / 由配速和步频计算步幅
- **算法**: `src/logic/cadence-stride/calculator.js`

#### 体重建议页（已实现）
- **数据源**: `src/data/bmi.json` — 成人身体状态 4 档 + 跑者层级 5 档（区分性别），每档含颜色
- **输入**: 体重（kg）、身高（cm）、性别（男/女）
- **算法**: `src/logic/bmi/calculator.js` — `calcBMI` 计算 BMI；`findAdultStatus` 判定成人身体状态（偏瘦/正常/偏胖/肥胖）；`findRunnerLevel` 判定跑者层级（需注意身体健康/世界顶尖精英/大众精英/健康完赛/新手）
- **横轴**: 两条百度式彩色热力图（成人 + 跑者），由 `src/pages/bmi/components/heatmap-bar.vue` 渲染，标注临界 BMI 与对应体重
- **说明页**: 「跑者如何理解 BMI」→ `pages/bmi/understanding/index`，内容由 `src/logic/bmi/understanding.js` 结构化定义

#### 跑步课表页（开发中）

## 扩展指南

### 添加新功能模块

1. 在 `src/pages/` 下创建新目录和 `index.vue` 页面组件（参考现有功能页模板）
2. 在 [src/pages.json](src/pages.json) 的 `pages` 数组中添加路由配置，设置 `"navigationStyle": "custom"`
3. 在 [src/pages/index/index.vue](src/pages/index/index.vue) 的 `menuItems` 数组中添加新模块（指定 id、title、icon、colorClass、path）
4. 为新模块选择合适的颜色和图标

### 替换"开发中"模块

九宫格 9 个模块均已分配颜色，当前仅剩 id 为 9（跑步课表）处于开发中。将对应 `menuItems` 项的 `path` 属性设置为实际页面路径（如 `/pages/training-plan/index`），并移除页面内的"开发中"占位内容即可上线。

## 开发注意事项

### uni-app 跨平台约定

| 注意事项 | 说明 |
|----------|------|
| HTML 标签 | 使用 `<view>` 替代 `<div>`，`<text>` 替代 `<h1>/<h2>/<p>/<span>`，`<image>` 替代 `<img>` |
| CSS 单位 | 使用 `rpx` 而非 `px`（750rpx = 屏幕宽度） |
| CSS 限制 | 避免 `:hover` 伪类（小程序不支持）和 `cursor` 属性（小程序无效） |
| 导航 API | `uni.navigateTo({ url: '/pages/xxx/index' })` 跳转，`uni.navigateBack()` 返回 |
| 页面位置 | 所有页面必须在 `src/pages/` 目录下 |
| 路由配置 | 使用 `pages.json` 配置路由，不使用 vue-router |
| 自定义导航 | 在 `pages.json` 中设置 `"navigationStyle": "custom"` 以使用自定义 header |
| 平台判断 | 使用 `#ifdef MP-WEIXIN` / `#ifdef H5` / `#endif` 条件编译 |

### 代码风格

- 使用 Vue 3 Composition API（`<script setup>`）
- 保持组件的单一职责
- 页面组件放在独立目录中，命名为 `index.vue`
- 全局样式变量定义在 [src/uni.scss](src/uni.scss)
